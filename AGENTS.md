# Project Working Rules

- Keep extension source, scripts, generated builds and tests under `app/`; keep documentation and documentation media under `docs/`. The repository README files and Git configuration files remain at the repository root.
- Do not use local Docker, WSL or other virtualization environments. Close browser tabs and browser processes created for a task when they are no longer needed.
- Do not commit browser profiles, recordings, ZIP exports, credentials, user data, dependency directories or generated builds. Use only synthetic data in published examples and media.
- When behavior or usage changes, update both root READMEs, the relevant files in `docs/`, and `docs/CHANGELOG.md`; refresh screenshots or the demo when they would otherwise be misleading.
- The project owner requests that subsequent updates and their release notes be pushed to `origin` as part of the authorized task. Check the remote and worktree before pushing, and preserve unrelated work.
