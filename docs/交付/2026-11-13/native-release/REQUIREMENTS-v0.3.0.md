# v0.3.0 release 需求收口

## 决策依据

用户最新明确不建设任何隔离环境，要求修复后编译打包交付一个release。本版直接在当前Windows原生环境执行真实验证，保留原有四操作/全已授权普通页面/原值本地处理；不继续等待旧草案选项或以旧环境计划阻止编译。最终验收以实际执行报告为准，不把历史静态pass替代当前结果。

## 已明确的取舍与边界

- 四项主要操作不增加查看、导入、回放、自动删除、范围选择或未批准的产品入口。当前本地历史批次不自动到期；更新卸载/分享/副本保留由说明明确。
- 支持环境为本机Windows正式版Chrome实测，Manifest125下界保留技术依据但不声称125真机已测；macOS、其他设备及真实客户ERP未验证。
- 自动化在自己的临时扩展副本预授测试域权限；真实发布包保留optional host permissions，原生权限弹窗人工交互是安装步骤，不伪造已自动验证。
- 短事务/采样、截图限频/合并、分片整页和Canvas表示均可有部分/不可得/未知；关键记录以原事件状态为准。0gap不证明绝对完整，ready只表示生命周期与可导出。
- 资源有局部预算和明确缺口，支持规模只引用实际样本；不在本版为无限包改造CAS/微服务/全局强一致或强行完整ExportJob，无法观察的字节/状态不补造。
- 最终报告要如实列先失败与后修复/重跑，不削弱业务断言换通过。

## 发布门

当前编译/完整JS与Python回归、当前候选主UI与ERP端到端、重点生命周期组、完整50场景矩阵和两个release包内容/解压加载检查均需有实际执行证据。最终文件与VERIFICATION/包hash绑定；未过的必需门不能认定release完成。
