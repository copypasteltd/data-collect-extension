# 逻辑记录 v0.3.0 — 本地 release

本版按用户明确要求直接在现有Windows原生环境修复、编译和验证，未建设或切换隔离环境。扩展只需Chrome，独立解析工具需要Python3.9+标准库。没有自动公开GitHub Release/商店发布。

## 主要修复

- 每个事件批次有独立确认结果：确认、明确拒绝、部分失败、提交未知不混同；累计失败数不再污染另一传输。
- JS、Python及归档派生统一分段终态，拒缺片、重复、错误长度、Failure冲突和End后的额外数据，保留UTF16及复杂值原样表示。
- 新批次有受控准入、持久关闭写与同事务seal水位；迟到任务保持原会话归属，终态不再变更原始证据集合。
- 修复停止流程封存水位读取无等待边界：底层读取异常时进入明确失败/中断，不永久占用停止入口。
- 数据库字段字典保留来源命名空间，跨站同名库不再直接合并；未知分区/实例保守处理。
- 原始读取失败与传输确认未知分开；采集因未确认提前结束时，即使迟到ACK归零也保留需核验标志。
- 导出与停止控制分离；录制时不新开历史导出，陈旧状态响应不覆盖新批状态。
- Blob生成后的下载启动/完成/查询等待有边界、轮询与事件双路；超时尽力取消并明确最终状态未知，原本地批次仍可检查重试。
- 可选producer/exporter及派生规则版本、固定枚举存储失败诊断，旧批版本未知不补造。
- 测试runner增加有界退出/己有资源清理回执、候选输入身份及结构化结果；故障注入适配append-only writer，不删除必要断言。

## 保留的产品行为

四项主要操作仍为开始/停止/选择批次/导出，不增加内容查看、导入、回放、自动删除或新的范围配置。默认记录同profile所有已授权普通HTTP(S)窗口/标签，包括新开页；关闭侧边栏不停止后台录制。记录与SQLite索引保留原值、ZIP未加密，不主动上传。

## 验证与交付口径

当前版本必须由真实编译、JS/解析工具回归、Chrome多批录制导出、故障/生命周期、采集矩阵及本地ERP证据流程验证；结果以同目录VERIFICATION.json/本版验收报告为准，不沿用历史0.2.0通过数。修复前失败和重跑结果在报告中区分。

## 仍需注意

- 完整性hash不证明来源可信；生命周期已停止不等于所有内容完整。需检查记录包缺口、未确认、部分/不可得状态。
- 截图可合并/缺失、整页分片非原子，Canvas不保证屏幕等价；IDB/Cache为起止/短事务采样，不是全库实时快照。
- 浏览器限制、受限页面/框架、未观察路径、服务端内部逻辑和任意大小/时长都不能保证。真实GPU/最低Chrome125/macOS/目标业务站点的未测范围不写成已过。
- 当前没有自动到期/逐批删除UI。更新前先导出，保留原安装目录并刷新；卸载可能清除本地批次。
- 自动化使用自己的测试profile与本地假数据，权限预授样本不证明原生权限弹窗已验证；不会关闭用户已有浏览器。

## 安装

解压logic-recorder-chrome-v0.3.0.zip，在chrome://extensions启用开发者模式并加载直接含manifest.json的目录。详细更新、恢复和数据处理见同目录INSTALL.md。使用前核对SHA256SUMS.txt，外部索引/分享仍需保护原值。
