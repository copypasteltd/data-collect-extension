# v0.3.0 本机原生 release 范围

## 最新决定

用户已明确“不做任何隔离环境，收口修复、编译打包交付一个release”。本次不建设或切换OS隔离，不使用Docker/WSL，直接在当前Windows原生环境执行开发验证。此前有关隔离资格的阻塞属于历史记录，不再作为本次发布前置；真实执行结果逐项登记，未测或失败不改称通过。

## 本版产品边界

- 保留本机Chrome扩展、全已授权普通HTTP(S)页面默认范围、四主要操作（开始/停止/选择批次/导出），不添加内容查看/导入/回放。
- 原值本地存储，ZIP未加密，不主动上传记录；继续明确含其他普通窗口/新标签与敏感原值的影响。
- 本版修复明确正确性/可用性、封存/身份/分段/诊断/控制与验证工具缺口；不为尚未实证的优化强上微服务/CAS或承诺任意规模零缺口。
- 未授权的自动删除、范围重设、内容脱敏/加密、额外产品入口不加入本版；本地批次不会自动到期，操作说明明确。
- 验证使用本机Windows正式版Chrome和合成本地页面/数据，不访问真实ERP、凭据、用户浏览器profile或业务记录。测试创建的独立user-data-dir是防干扰测试数据目录，不是建设隔离环境，也不作OS安全声明。

## 必过发布门

1. 当前源码真实编译成功、JS回归和Python消费者回归通过；异常发现修复后重跑。
2. 当前候选Chrome录制/停止/多批选择/分别ZIP导出/外部校验和原值定位实际通过。
3. 关键生命周期、重试/超时/关闭/恢复/分段语义在真实浏览器或明确的单元层核对。适用完整采集矩阵逐项记录pass/fail/skip；不得以旧构建结果抵新构建。
4. 支持规模仅以实际合成持续录制样本和可读取性能记录为依据；单包/时间/页面无限规模、最低Chrome125与macOS实测不自动声称。
5. Release ZIP只含编译扩展加载文件或解析技能；不含profile/node_modules/真实数据/发布凭据；版本一致、SHA256、包内容和解压加载验证可复核。

## 交付与发布

本地输出app/release/v0.3.0，包括Chrome扩展、解析工具ZIP、校验值、安装/更新/数据处理说明与如实验证报告。不自动GitHub Release或商店公开发布；代码同步遵循仓库规则另记录结果，不能把推送失败掩饰为成功。
