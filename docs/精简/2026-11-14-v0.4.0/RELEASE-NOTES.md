# v0.4.0 — 轻量业务记录版

按用户批准的需求减量方案实施；旧数据不迁移、不救援，也不删除。当前是本地release交付并更新原插件目录，不自动创建新GitHub Release。

## 需求收口

- 根业务标签+必要授权框架+一个可明确归因子页，不再全profile捕获。
- 保关键操作、稳定表单值/前值、导航/关键页面状态/短命提示、一个结构DOM表示、必要CSS资源、视口PNG和业务接口样本。
- 移除默认全计算样式/伪元素/全主题字典、Storage轮询、Cookie快照、全库/Cache镜像、全页截图/Canvas另存字节、全JS/视频/上传字节镜像和所有实时流正文。
- 新采集与导出入口不导入旧重型通道，权限移除cookies/unlimitedStorage；当前业务来源授权，不自动请求全网。

## 有界保存与直接导出

- 新数据库logic-recorder-flow-v1，普通接纳63MiB/总64MiB、48MiB警告，类别子预算，单正文2MiB；预算拒绝与传输失败分开。
- 每会话SHA256内容去重；相同原字节一次保存，多次观察引用仍保；跨类别复用分别计类别防绕限。
- append事件+内容+预算单事务，captureKey持久幂等、seq/owner写门、最终唯一stop与seal；容量后保留收尾空间。
- v3包只封装已保存事件/内容与轻清单/hash，不在导出时展开数千万行主题/字段分析。独立Python工具支持v1/v2/v3，v3轻内容引用索引。

## 验收中修复的关键边界

- 空白子页候选待URL/归属确认；未来点击不能倒因果认领先开无关页。
- 同owner同文档重复注入保留队列/ACK，独立generation nonce防批次标识冲突；后台每授权文档只注入一次，iframe导航不重置root。
- 200ms校验提示即时轻量原文证据，不因快照节流消失；不是全Mutation日志。
- 未知/无权frame的WS不保存其URL，用固定来源缺口，不推定根页权限。

## 使用与限制

仍仅开始、停止、选批次、导出四主要操作，不增加复杂模式/内容查看/导入/回放。页间/框架权限不足、预算排除、未观察状态必须检查缺口。新列表不显示旧库批次。

精确验证结果以REPORT.md/VERIFICATION.json为准，不沿用旧50重型矩阵；60秒样本和20轮短业务P95是不同负载，不互相伪称。独立接收者仅凭包重建关键页面/业务作为可用性证据，不是原站源码或像素级恢复。

更新前确认停止，备份后覆盖原加载目录，再对原扩展刷新；不要卸载、清浏览器数据或加载成另一个路径的第二份。完整步骤见INSTALL.md。
