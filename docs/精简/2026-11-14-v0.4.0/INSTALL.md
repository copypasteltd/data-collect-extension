# 逻辑记录 v0.4.0 轻量业务版：安装与使用

## 这次改变了什么

这是用户批准的需求减量版本，不是旧全量模式的压缩开关。只记录开始时选择的根业务标签、已授权必要框架、以及一个可明确归因到已记录可信操作的业务子页。无关现有标签、其它窗口和无法归因的新页不纳入；切换标签不会改变录制根页。

保留开始、停止、选择批次、导出四项操作。不提供复杂录制档位，不提供内容查看/导入/回放。只记录已观察路径，不恢复原网站源码、完整离线数据库、登录态或所有像素/未访问分支。

## 首次安装

解压扩展ZIP至固定目录，在chrome://extensions启用开发者模式→加载已解压的扩展程序→选择直接含manifest.json的目录；点击/固定扩展图标。录制不需要Node/Python。

## 录制

1. 先切到有权记录的业务页面，再打开侧边栏点击开始。原生提示只请求当前来源访问权限，不主动请求所有网站。此前安装已授予的网站权限可能保留，但本版内部scope仍限制根流程，不扫描所有授权标签。
2. 等待录制就绪后做关键步骤。点击/提交、字段稳定值及可知前值、选项、关键键、滚动终点，以及弹窗/下拉/校验等页面状态会尽力保存。短暂业务提示有有界原文状态事件，不依赖500ms后仍存在。
3. 同标签跨域导航仅在已授权来源继续；未授权框架/来源明确缺口。可信操作打开、有opener且可证明时间归属的一个子页可纳入同预算。无opener/先开页后点击/第二个子页不自动接管。子页刚纳入后仍需采集器就绪，开始之前操作可能未观察。
4. 停止后选择批次，导出。关闭侧边栏不会主动停止录制。

## 保存什么／不保存什么

- 一个规范结构DOM表示、真实表单property及必要组件结构；必要CSS规则/资源按内容hash一次保存，多次观察留引用。
- 关键视口PNG而非整页分片；不另采Canvas所有像素或视频。必要画像/字体尽力只从浏览器已加载资源读，不主动重放HTTP。
- 业务XHR/Fetch的请求响应样本、原URL/查询/请求头、状态、时间与身份；相同正文复用，不能因为URL相同抹掉不同结果。文档原始HTTP HTML不与结构DOM重复保存。
- **默认不采**：全元素计算样式/伪元素属性普查、主题字段字典、Cookies全域快照、Storage轮询、IndexedDB全库、Cache镜像、全资源与上传文件字节、WebSocket/SSE正文流。按策略未采不等于不存在。

## 容量与完成状态

每批总64MiB（67108864字节）；48MiB预警，普通接纳63MiB，另1MiB预留停止/清单相关元数据。子预算：正文24MiB、DOM16MiB、资源8MiB、截图12MiB、元数据4MiB；单正文2MiB。相同内容只按实际存储一次，但跨类别引用仍受各自类别限制。达到预算自动受控停止，不干预业务页面、不自动删记录。

“按容量停止/部分记录可导出”不是传输失败；真正存储/通信或收尾异常仍中断。ready/文件校验通过不代表所有采集内容完整。某个必需内容被策略排除时，该流程重建的完整性必须另判，不伪称已覆盖。

保存预算不是Chrome进程内存硬上限；CDP读取未知长度正文无法保证物理流式硬限，已有预检查/后验拒绝与诊断明确限制。超限metadata保原因而不是静默裁正文。

## 新包结构与解析

记录格式v3/business-flow-v1：manifest.json、integrity.json、timeline/events-NNNNN.jsonl、contents/<SHA256>.bin。payload顶层内容引用给出contentId/hash/size/MIME/类别，原字节独立存储。主导出不解析生成主题/字段/接口报告。

独立解析工具Python3.9+标准库可校验并生成新SQLite索引，输出路径必须不存在：

```powershell
python scripts/index_archive.py recording.zip --output new-index.sqlite3
```

工具位于extension-logic-clone目录。SQLite保持原始事件、文件hash及content_refs，分析离线按需做，不对真实后台重放写请求。

本版Windows原生Chrome合成数据测试，不建隔离环境；专用测试profile只防干扰。原生权限弹窗/最低Chrome125/macOS/真实业务站点未自动认证。不同规模/页面脚本与GPU不可外推为任意站点保证。最终真实验证、体积和P95见REPORT.md/VERIFICATION.json。
