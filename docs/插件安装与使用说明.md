# 安装与使用说明

本插件的侧边栏仅提供开始录制、停止录制、选择录制批次和导出 ZIP。它不在插件内展示页面、接口、截图或其他采集内容，也不提供导入和复现界面。

## 安装

准备 Chrome 125 或更高版本。从 [GitHub Releases](https://github.com/copypasteltd/data-collect-extension/releases) 下载 `logic-recorder-chrome-v0.1.0.zip` 并解压，在 `chrome://extensions` 开启开发者模式，使用“加载已解压的扩展程序”选择包含 `manifest.json` 的解压目录。

从源码构建还需 Node.js 20 或更高版本及 npm。在项目的 `app/` 目录执行 `npm ci` 和 `npm run build`，然后在扩展管理页加载 `app/dist`。更新源码后重新构建并刷新扩展。

## 录制和导出

1. 打开需要记录的 HTTP 或 HTTPS 页面，点击扩展图标打开侧边栏。
2. 点击“开始录制”，按 Chrome 提示授予网页访问权限。默认启用截图与画布静态采样，尝试记录所有已授权的普通网页，包括开始时已打开及之后打开的网页。
3. 在浏览器中完成业务操作，然后点击“停止录制”。侧边栏关闭不会主动停止后台录制。
4. 在“录制批次”中选择需要的批次，点击“导出记录包”。不同批次可以分别选择并重复导出。意外中断的批次可导出已保存部分。

列表只展示批次时间、简短标识和完成或中断状态，不展示网页标题或采集内容。后台错误或浏览器权限拒绝会在操作时提示。

## 记录包

ZIP 包含 `manifest.json`、`integrity.json`、`timeline/events-*.jsonl`、`screenshots/` 和 `resources/`。清单记录批次状态、事件分段和能力限制；完整性文件包含各文件大小和 SHA-256。每行事件包含类型、时间、批次、页面或标签标识以及对应数据。

`page.snapshot` 的 `sourceHtml` 是采集时序列化的页面 DOM，`sourceStatus` 和 `sourceLength` 说明采集结果；`html` 为不含可执行页面脚本的隔离快照。原始 DOM 超过 150 万个 UTF-16 代码单元或无法读取时不保存。它不是原始 HTTP 字节，不包含 Shadow DOM 或未体现在 DOM 属性中的实时表单值；部分组件结构和操作状态另见快照及事件。旧记录不一定包含 `sourceHtml`。

网络事件以 `requestId` 关联请求、响应和结束状态。浏览器以 Base64 返回的文本会尝试按声明字符集解码；解码失败或文本超过解析上限时，在原始字节不超过 400 万的条件下保留 Base64 并记录 `textStatus`。浏览器未提供内容、编码无效或超过限制仍可能造成缺失。

## 数据和权限

录制原样保存浏览器提供的内容，可能包含密码、认证头、Cookie、个人信息、业务数据和未遮挡截图。ZIP 不加密，任何取得文件的人都可能读取内容。请仅录制有权使用的页面，并按需要控制保存和分享范围。

网页访问权限按开始录制时 Chrome 的授权结果使用；浏览器内部页面、扩展页面和其他受限页面不能按普通网页采集。Cookie 按域共享，变更事件不能可靠识别具体页面，可能包含同域其他端口的变化。扩展不主动上传记录。

## 当前限制

- 录制开始前发生的操作和请求无法补录；页面切换、浏览器关闭、调试器中断、跨域限制或页面销毁可能产生缺口。
- 操作截图受浏览器频率、活动标签及异步时序限制，可能共用或缺失。每次快照最多尝试 5 个 Canvas、每个最多 50 万像素；跨域污染、GPU 绘制或上限可能导致画面缺失。
- 普通输入及操作前值最多保存 10,000 个 UTF-16 代码单元；单个正文文本节点最多 500,000 个，隔离快照及原始 DOM 分别有 150 万个代码单元上限。
- `localStorage` 和 `sessionStorage` 每秒及停止或离开时采样；每种最多读取 200 个键，单值超过 4,000 个 UTF-16 代码单元会标记超限。采样之间的短暂变化可能遗漏。
- IndexedDB 和 Cache Storage 仅进行有上限的开始和结束采样；数据库二进制值、循环结构及超限内容可能不完整。缓存只保存有限的名称与请求元数据，不保存缓存响应内容。
- 文件选择与拖放仅记录有限的文件名和元数据，不采集文件内容；剪贴板事件不保证包含剪贴板内容。HTTP 重定向中间响应主体和部分网络主体也可能不可得。
- 导出和导入兼容检查存在体积、文件及事件数量限制；当前侧边栏不提供导入功能。超限记录包可作为备份，但其他解析工具需自行处理。
- 记录只覆盖已观察的业务路径，无法保证恢复未访问分支、服务端逻辑或完整可部署网站。技术方案和详细限制见[技术开发文档](Chrome扩展技术开发文档.md)。
