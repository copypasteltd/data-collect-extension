# 逻辑记录插件：安装与使用

版本：开发验证版<br>
更新日期：2026-11-10

## 安装

1. 打开 Chrome，在地址栏进入 `chrome://extensions`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本仓库的 `app/dist` 文件夹。
4. 在 Chrome 工具栏的扩展菜单中找到“逻辑记录”，可将其固定到工具栏。

当前构建要求 Chrome 125 或更高版本。源码修改后需在 `app` 目录重新执行 `npm run build`，再到扩展管理页面点击刷新。

## 开始和结束录制

1. 在 Chrome 打开需要记录的 HTTP 或 HTTPS 网页，点击“逻辑记录”图标打开侧边栏。
2. 选择“当前站点及其新标签”或“所有打开的网页”。后者会申请所有 HTTP 和 HTTPS 网站的访问权限，仅在确实需要并有权记录时选择。
3. 按需选择是否记录截图和非认证 Cookie 值，确认授权说明后点击“开始录制”，并在 Chrome 请求权限时确认。非认证 Cookie 值默认不保存；开启后仍不能保证识别出所有凭据，分享前需检查。
4. 等待状态显示“录制中”，再执行需要记录的业务流程。录制前已经发生的请求无法补录；如需记录初始加载，应在开始后自行刷新或重新进入页面。
5. 完成操作后点击“停止录制”，等待状态结束。录制记录保存在本机，可在侧边栏查看或下载 ZIP。

多个侧边栏同时发出停止请求时，后续请求会提示等待，已经开始的整理继续进行；真正的整理失败会将记录标记为异常中断，保留可用部分。

录制网络时 Chrome 可能显示调试提示；调试连接被关闭或其他工具占用时，网络采集可能不完整，侧边栏和记录中会有提示。录制期间工具栏图标会显示状态标记。

## 查看和分享

- 在“录制记录”中点击眼睛图标，可以直接在侧边栏查看本机记录；点击下载图标可以生成 ZIP。
- 导出记录包或清单时请保持侧边栏打开，直到浏览器下载完成；若下载中断或无法确认状态，侧边栏会提示错误，可重试下载。
- 接收者安装相同插件后，在侧边栏点击“导入记录包”，选择 ZIP。查看、逐步复现、页面、流程、接口和采集报告均在侧边栏内操作。
- “逐步复现”展示已记录的操作；可切换操作前最近的截图与该操作关联的操作后截图，并查看截图时间和未取得原因。最后一步完成时，若有对应的操作后截图会自动切换显示。操作前截图并非保证紧贴操作发生时的画面。
- 截图上的近似操作位置仅在标签页、页面实例、网址、截图时间和视口等条件能够确认时显示；页面实例缺失或不一致时仍可查看截图，并使用侧边栏备用控件。与操作发生在同一毫秒的截图不会被当作确定的操作前画面。
- “逐步复现”可切换到“页面”，在操作前的隔离快照中点击或填写当前步骤的目标元素；完成后进入下一条已记录的操作。目标无法定位、控件状态不一致或没有合适快照时，可使用步骤按钮及辅助控件继续查看。
- 最后一步完成后，侧边栏会尝试显示后续记录的页面变化或停止时快照；如果记录到随后激活的标签页，也会尝试显示该标签页的状态。新标签与操作的关系只按时间推测；跳转后的页面未取得时会明确提示。
- 新记录在截图与操作视口一致且时间接近时，可能显示近似操作位置；页面变化、滚动位置不一致、时间相差较大或旧记录缺少视口信息时不显示标记，可使用上一步、下一步查看记录路径。
- 截图使用浏览器实时画面，连续操作可能共用截图。插件会标记截图开始与完成时间；如果截图期间发生操作，或截图与操作之间有其他操作、页面变化，不会显示近似操作位置。调试连接可用时会更频繁尝试截图，但仍不能保证每次操作都有独立截图。
- 新录制的复选框、单选框和下拉选择可在侧边栏使用对应控件逐步复现。能够确认时会显示操作前的选择；未取得、选项发生变化、选项内容过长或脱敏后无法区分时会提示状态未确认。旧记录或选项数量超过限制时，可使用步骤按钮查看。
- 在时间线选中操作后，可从该操作直接进入逐步复现。
- 操作后若页面已跳转，截图会标注页面变化；回放不会在该截图上叠加原页面的操作位置。
- “流程”中的候选请求可点击查看原始证据，并从请求返回可能相关的操作。插件按标签页、可用的页面来源、网址和一秒时间范围进行筛选；来源不明确时会标注，关联不等于已确认的业务因果关系。无法确认请求来自哪个页面时，不会将主页面快照作为该请求的确定画面；旧记录的近似页面状态会标注仅供参考。页面及接口清单只包含本次实际观察到的内容；不满足关联条件的请求仍可在时间线和接口清单中查看。
- 查看请求及其后续响应时，侧边栏关联请求发起的页面；同页会展示截至所选事件的可用状态，期间发生跳转时回退到请求时刻。跳转、刷新或路由变化后未取得可确认的新页面快照时，不会直接沿用旧页面，并会提示无法确认。旧记录缺少页面实例或导航事件时，页面状态仍可能只能近似判断。
- “流程”按事件发生时间、标签页和页面实例整理；同一网址重新加载后会显示为独立片段。旧记录缺少页面实例标识时，区分能力取决于已记录的导航事件。
- 在“接口”中可下载 OpenAPI 规范草稿；字段类型和请求样本来自录制，不代表未经观察的完整接口契约。
- 规范草稿按内容类型整理样本并合并已观察字段，每种内容类型最多附带 20 个示例；完整采集记录仍保留在记录包中。
- 草稿的字段推断有深度及数量限制：最多分析六层结构、每个对象的前 200 个字段和每个数组的前 50 项。
- 录制记录默认存储在扩展本机数据中。卸载扩展可能清除本机记录，应在卸载前导出需要保留的数据。

## 数据和隐私

录制包可能包含页面内容、截图、用户输入、图片、接口数据及业务资料。密码、常见认证字段及部分敏感字段会尝试隐藏，但自动识别无法保证覆盖所有敏感内容，分享前必须检查记录；建议优先使用已授权的测试数据。

对于录制的网址和可识别的资源地址，片段（`#` 后部分）解码后若包含常见敏感名称，会整体隐藏该片段，可能同时隐藏业务路由。此规则并不覆盖所有凭据形式，也不会自动修改已有记录。

截图在保存前检查可识别的敏感输入区域，包括开放和关闭式页面组件，并尝试遮挡。组件检查不可用、嵌入页面没有权限、坐标无法确认或截图期间页面发生变化时，对应截图可能跳过并在采集报告中显示。图片资源和页面文本仍可能包含敏感信息。

记录包没有默认加密；任何收到 ZIP 的人都可能查看其中的数据。请按组织的数据管理要求决定保存位置和分享范围。

## 当前能力边界

- 本插件记录浏览器实际观察到的行为；受 Chrome 权限、受限页面、跨域框架、调试连接和站点实现影响，不能保证所有数据均可取得。请查看侧边栏中的“报告”和具体事件状态。
- 关闭或跳转页面时会尽快发送待处理操作，但浏览器销毁页面时仍可能中断尚未送达的数据。
- 页面快照是隔离的静态展示，不执行原站脚本；页面复现依据已记录的步骤和页面变化推进，不会向原站提交数据，也不等同于重新运行原站全部功能。无法确认页面实例、目标元素或控件状态时可能无法在页面内操作。
- 普通表单输入与页面变化按事件顺序还原；富文本可结合已记录的文本及节点变化保留部分格式，无法确认结构时可能只能按纯文本显示，并在页面状态中提示。
- 页面持续发生变化时，快照调度会尽力在约 2 秒内保存一次状态，避免持续更新无限推迟快照；离开页面时也会尝试保存待处理快照。浏览器节流、页面繁忙、页面销毁或快照限制仍可能导致状态延迟或缺失。
- 开始录制时会尝试从已加载的页面图片生成本地 PNG 副本，不主动重新请求网站。副本只保留当前静态画面；跨域限制、纯 CSS 背景图和未加载图片可能无法读取。每个标签页最多保存 50 张、单张最多 100 万像素及 1.5 MB、总量最多 10 MB；所有标签页共享约 6 秒的检查时间。
- 页面变化中新增或更换的图片可在对应资源已成功采集时还原；查看器会结合可用的页面实例、嵌入页面和导航记录筛选资源，避免将旧页面或其他页面的同地址图片误当作当前画面。来源不明确、超出资源限制或浏览器未提供的图片可能无法显示，并在页面状态中提示；旧记录缺少页面来源信息时仍可能无法完全区分。初始图片采集不足会在报告中提示。
- 页面快照可还原已采集资源对应的单张 CSS 背景图，每次快照最多检查前 2000 个元素。多层背景、`image-set` 和未采集的资源不保证还原；超过检查上限会在报告中提示。
- 页面快照会保留可直接读取的样式，并尝试使用录制期间取得的外部样式；外部样式和字体也会按可用的页面来源及导航记录筛选。对于已取得的外部样式表及可读取的内联、同源和构造样式表，插件会尝试离线还原录制期间实际加载的 WOFF、WOFF2 字体。单个字体超过 1.5 MB、单次回看字体超过 10 MB、不支持的格式、录制前加载或未取得的资源可能缺失，并在可以识别时提示；组件内字体能否显示还取决于浏览器对组件字体作用域的支持。录制前已加载但无法直接读取的跨域样式不会主动重新请求，可能缺失；`@import` 和样式内其他资源链接不会在回看时联网加载。请在开始录制后刷新页面以采集初始加载请求。
- 快照中单个可读取的页面或组件样式文本最多保留 500,000 个 UTF-16 代码单元，超限会标记截断；样式仍需经过敏感信息处理，且整个页面快照有独立大小上限。旧记录中已经丢失的样式无法自动恢复。
- 页面和组件快照中的单个正文文本节点最多保留 500,000 个 UTF-16 代码单元，超限时保留前缀并标记截断；快照总大小上限为 150 万个 UTF-16 代码单元，超限时整份快照不保存。快照间的单次文本变化仍有 10,000 个代码单元的限制；录制列表和采集报告会提示快照截断或缺失。旧记录中丢失的正文无法自动恢复。
- 插件会尝试记录开放和关闭式 Shadow DOM 组件内部的点击、输入、选择、提交、按键、指针、焦点、拖放、剪贴板操作及滚动，并保存组件路径。剪贴板操作不代表一定保存剪贴板内容。页面快照会尝试保存组件的静态结构、表单状态和可读取的样式，在侧边栏隔离展示。
- 插件会尝试记录组件内的节点新增、修改和删除，并在快照之间还原这些变化。新组件刚创建时的极早变化、无法穿过组件边界的事件，以及部分背景、样式和资源仍可能缺失；检查到组件或采集不完整时会在报告中提示。每个快照最多保存 100 个组件和 10000 个组件内元素，超过限制会标记截断，应结合截图核对。
- 滚动记录会区分整页和列表等内部区域，保存区域位置及尺寸；页面快照会尝试还原已记录的滚动位置。侧边栏宽度、字体或缺失资源可能使显示位置与原页面有所差异。每次快照最多检查前 10000 个元素并保存 200 个非零的内部滚动位置，超过时会在报告中提示；旧记录可能没有完整的滚动状态。
- 复选框、单选框和下拉框的选择状态会随操作记录；单次选中超过 200 项时会在采集报告中提示不完整。旧版本记录包可能没有这些状态。
- 逐步复现会优先使用浏览器在输入前提供的可确认原值；自动填充或脚本触发等情形可能无法取得，界面会标注状态未确认。原值可能因脱敏或过长而变化，界面会相应提示。复现会按页面实例区分连续输入；缺少页面实例标识的旧记录只能根据网址和元素位置判断，刷新前后的输入可能无法完全区分。
- 普通文本输入和可确认的操作前值最多保存 10,000 个 UTF-16 代码单元，超过时保存前缀并在报告及复现中提示；页面快照中的普通表单值也有相同上限。旧版记录可能在 4,000 处截断但没有截断标记。
- 站点数据库和缓存仅采集有上限的开始和结束快照；缓存只保存名称、请求地址、方法和模式，不保存请求头、请求体或缓存响应内容，也不会为采集清单重新请求网站。数据库和缓存的中间瞬时变化、未观察到的服务端实现和未走过的业务分支无法由这些数据完整还原。
- 每个页面框架每次缓存采样最多检查 20 个缓存、每个缓存 50 个请求、总计 300 个请求，采样时间上限约 2.5 秒；请求地址和缓存名称超过 10,000 个 UTF-16 代码单元时不保留原值。超限、超时及不可读取会在录制列表和报告中提示。浏览器接口需要打开已有缓存才能枚举请求；若网站恰好在插件检查缓存存在后、打开前删除它，浏览器可能重新创建空缓存。旧记录只包含名称。
- 数据库快照中，大整数、映射、集合、正则表达式、非有限数值和 `undefined` 使用带 `$type` 的 JSON 结构表示；日期保存为 ISO 字符串。二进制值或键只保存类型与大小，循环引用及不支持的类型不完整保存，相应记录带 `issues`，并在录制列表及报告中提示。旧记录中的缺失内容无法补回。
- 每个页面框架每次数据库采样最多检查 20 个数据库、每个数据库 30 个对象仓库、每个仓库 100 条且总计 500 条记录；单个值序列化后最多 10,000 个 UTF-16 代码单元，总值内容最多 200 万个。每个对象、数组、映射或集合最多保留 200 项，单个键或值最多遍历 2,000 个节点和 12 层；超限内容会标记。浏览器未开放或超时的数据库也可能缺失。
- `localStorage` 与 `sessionStorage` 每秒采样，停止录制或页面离开时补采；每种存储最多读取 200 个键，非敏感值超过 4,000 个 UTF-16 代码单元时只记录超限标记。存储不可读、键或值超限时会在报告中提示；采样间的短暂变化仍可能遗漏。特殊键 `__proto__` 另在事件的 `specialEntries` 数组中保存；旧版记录中被隐藏的会话存储不能恢复。
- 常见文本、JSON 接口主体按规则处理；未知二进制、超过大小限制或浏览器未提供的主体可能不保存。截图、资源、数据库和响应的限制或失败会尽可能记录。
- 浏览器以 Base64 提供可识别文本响应时，会尝试按响应声明的字符集解码，未声明时按 UTF-8 解码，再进行脱敏；单个文本主体最多 100 万个 UTF-16 代码单元，Base64 解码最多 400 万字节。编码无效、浏览器未提供内容或超过限制时会标记并在报告中提示。无法确认原始响应字节时不能保证恢复原始内容。
- 浏览器在请求事件中省略较大主体时会尝试补充读取；读取失败、重定向归属无法确认或超过限制时，会记录相应状态。
- HTTP 重定向的各次请求及响应状态分别记录并关联；跳转响应主体不采集，最终响应按正常规则采集。
- WebSocket 文本消息按 JSON 或普通文本处理后记录；二进制消息仅记录收发方向和未采集状态。
- 当前站点模式按请求发起页面的协议、主机和端口判断范围，而非按接口目的地址判断；范围内页面调用跨域接口仍会尝试记录，范围外嵌入页面的请求、WebSocket 消息和对话框不会记录。无法确认请求、WebSocket 或对话框来源时会跳过并提示；录制前已建立的 WebSocket 可能因缺少握手来源而无法采集。旧版记录可能包含范围外嵌入页面的数据，分享前应检查。
- Cookie 在浏览器中按域共享而非按端口隔离；Cookie 变更事件无法可靠判定由哪个页面发起，可能包括同域其他端口造成的变化。此类事件标记 `source: domain_scope_unconfirmed`。
- 服务端事件流（EventSource）的消息、事件类型和编号会与对应网络连接关联；消息内容按文本规则处理。
- 侧边栏当前限制导入不超过 300 MB 的 ZIP、单文件展开不超过 50 MB、展开总量不超过 1 GB，并检查实际解压大小。导出时会对超过 300 MB 的包提示；对于长期流程，建议分段录制。
- 记录包以分段格式保存事件，提供校验清单。查看器支持本插件的版本 1 和版本 2 记录包；校验用于发现文件变化，不证明数据来源真实。

## 异常恢复

如果浏览器在录制中退出，重新打开后扩展会将上次任务标为“异常中断”，可查看或下载已经成功保存的部分。退出前仍在缓冲或写入中的数据可能丢失，不应当作完整录制。

如果插件后台在准备或结束录制时意外中断，重新打开侧边栏后也会显示“异常中断”；已完成归档的记录会保留完成状态。仅后台正常休眠再恢复，且录制状态仍然有效时，会继续显示录制中。

录制后台重新启动后，插件会根据已保存的网络事件尝试恢复调试连接仍可用的进行中请求，使后续响应继续关联。重启前尚未完成读取的请求体会标记不可用；重启期间未落盘的事件、已有 WebSocket 或跨进程框架的后续消息仍可能缺失，录制列表及报告会显示提示。浏览器本身退出后仍按异常中断处理。

页面采集消息发送失败或结束时无法完成数据收尾时，记录也会标记为不完整。请查看侧边栏中的提示和采集报告，并按需重新录制相关流程。
