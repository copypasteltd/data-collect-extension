# 逻辑记录 v0.3.0 安装、更新与使用

## 交付文件与环境

本版在当前 Windows 原生环境编译和测试，不建设或切换隔离环境、不使用Docker/WSL。扩展安装只需Chrome，无需Node.js/Python；Python 3.9+仅用于插件外解析工具。Manifest声明Chrome125+，实际已测浏览器和结果以[本版验收报告](<交付/2026-11-13/native-release/RELEASE-REPORT.md>)为准，未实测的平台/版本不自动保证。

交付目录为项目的app/release/v0.3.0，其中：

- logic-recorder-chrome-v0.3.0.zip：扩展加载文件；
- extension-logic-clone-v0.3.0.zip：独立解析技能；
- SHA256SUMS.txt、release-manifest.json：文件校验与打包清单；
- INSTALL.md、RELEASE-NOTES.md、VERIFICATION.json：使用说明、更新和实际验证记录（交付完成时一同提供）。

如通过文件分享收到本说明，以上名称均指同一交付目录中的文件，不需要先下载旧GitHub Release。公开发布不自动执行。

## 首次安装

1. 把扩展ZIP解压到固定目录；目录直接包含manifest.json、background.js、content.js、sidepanel.html、assets及icons。不能只复制manifest，也不能把ZIP自身选作扩展目录。
2. 在Chrome地址栏打开 `chrome://extensions`，启用右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含manifest.json的文件夹。
4. 在工具栏扩展菜单固定“逻辑记录”，点击图标打开侧边栏。

Chrome可能显示debugger/网站访问相关提示，使用前确认授权范围。自动化测试预授予测试站点权限，不等于原生权限弹窗接受/拒绝已自动验证。

## 从旧版本更新

- **先停止并导出需要保留的批次。** 录制进行中不要替换文件或刷新扩展。
- 优先覆盖原已加载目录，再在 `chrome://extensions` 点击该扩展的刷新按钮，以保留同一安装身份的本地数据。
- 不要为了更新先卸载；卸载可能清除本地数据库。移动加载目录/改变扩展身份也可能无法访问旧批次，导出的ZIP是独立备份。
- 旧v1/v2记录包继续由解析工具读取；旧终态批次没有新seal/provenance不补造。旧版已丢失/隐藏的原值不可恢复。

## 录制与导出

1. 仅打开已获授权的普通HTTP/HTTPS网页。建议使用专用业务profile；同一profile中其他窗口、新标签也属于默认范围，单独工作窗口并不隔离它们。
2. 在侧边栏点击“开始录制”，按Chrome提示允许访问网页。默认截图和Canvas静态采样开启，尝试接入已开及后来打开的获准普通页面。
3. 正常操作网页。点击“停止录制”结束；准备期间也可停止。**关闭侧边栏不会主动停止后台录制。** 退出浏览器/调试连接中断可能使批次中断。
4. 收尾结束后，在“录制批次”选择记录，点击“导出记录包”。录制中不启动历史导出；导出状态不会占用当前停止控制。可选择不同批次分别导出，中断批次保留已保存部分。

列表只显示时间、短标识和必要状态，不显示采集内容/网页标题。

- “已停止，可导出”：可尝试导出，不表示数据无缺口或已经业务验收。
- “已停止，需核验”：存在已知限制或未确认采集；请检查原始事件、manifest.session.coverage/诊断和分段。
- “录制中断”：仅保证已保存部分可尝试取回，不推定中断时未确认数据已经保存。

下载只有收到完成状态才显示成功。Blob生成后启动确认默认最多15秒、完成确认最多180秒；事件与轮询并用。超时/取消只说明等待结束和已尽力请求取消，不证明文件已删除或下载一定未开始；请先检查Chrome下载列表，再从仍保留的本地批次重试。构建大记录包本身可能较慢，此180秒不是整包生成时限。

## 错误与恢复

- 准备页面较多时保持准备状态，仍可停止；列表读取失败不会替代实时状态或禁止停止。
- 后台重启恢复失败时，停止尝试受控清理并封存为中断；已有终态批次不覆盖。无法确认归属时保守拒绝错误停止，等待状态可读后重试。
- 本地存储/封存失败会提示异常，已确认内容保持。不要反复开始新批次来掩盖错误；先导出可用部分、检查磁盘与浏览器状态。
- 新批次按owner/writer门和seal水位保存，终态后不接受新增原始记录；传输未知、采集中止与确定失败分别保存。
- 当前不会自动清理已导出的批次，没有逐批删除/内容查看/导入/回放界面。导出后本地副本仍保留；卸载删除与导出ZIP、外部索引是不同生命周期。

## 数据和隐私

记录原样保存可读取的输入、认证头、Cookie、文件字节、个人/业务资料及未遮挡截图。**ZIP和外部SQLite索引未加密，取得文件的人可读原值。** 扩展不主动上传记录，但本机备份/云同步/人工分享仍由持有人控制。不要在无权访问或无权保存的页面录制。

Cookie按域/分区可见性提供环境，变更不可靠对应具体页面/动作；来源标未知时不得解释为确定业务因果。

## 数据格式与限制

ZIP包含manifest.json、integrity.json、timeline/events-*.jsonl、screenshots、resources、indexes、data-dictionary和styles等。hash核对字节一致性，不证明来源可信。

- 原始DOM为序列化结果，不是原HTTP字节；Shadow、表单property与画布另有通道。原始/隔离HTML超过150万UTF16代码单元尝试引用分段，读取失败或缺段不得称完整。
- 输入事件内联前缀最多10000，长原值另分段；派生快照表单/文本仍可能裁剪，分段不会补回派生裁掉的内容。
- 每片100000 UTF16单位，非空引用/安全整数/长度数量/唯一confirmed End必须一致；同组Failure或End后额外片拒完整重组。空文件以内联空Base64表示。
- 独立Canvas通道与5项/50万像素的兼容预览不同；跨域污染、GPU、动态绘制或超时会缺失，PNG与屏幕合成不保证等价。
- 快速操作可能共用截图；整页分片各自有时间，非同一瞬间。
- Storage按周期/离开/停止采样；IDB/Cache以起止/短事务读取，非原子全库备份，无法保证捕获中间瞬态变化。
- 浏览器限制、受限框架、导航、连接断开、缓存淘汰/网络体不可得及大规模资源压力仍有明确缺口。
- 不保证任意长/大录制、未访问分支、服务器内部规则或完整可部署网站。支持和性能仅按本版实际样本说明。

详细schema、容量和读取规则见仓库内技能的references/archive-format.md；外部工具见[技能使用说明](<技能使用说明.md>)。

## 解析工具

技能ZIP解压后为extension-logic-clone目录，可放入Codex技能目录，已有目标先备份检查。也可直接在解压的技能目录中：

```powershell
python scripts/index_archive.py recording.zip --output new-index.sqlite3
```

输出文件不得存在；该SQLite仍含原值。需要分段重组或样式解码时分别使用reconstruct_payload.py、decode_computed_style.py；不直接执行记录的HTML/脚本或对真实业务重放。
