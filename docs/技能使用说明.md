## 校验与索引

在安装的skill目录执行，Python3.9+标准库，无需pip安装：

```powershell
python scripts/index_archive.py D:\recordings\session.zip --output D:\work\new-index.sqlite3
```

新索引不覆盖已有文件，源ZIP不变；核ZIP路径/size/SHA256、事件/内容/引用、v3可选账本及封存。metadata.archive_identity绑定整包身份。标准输出仅统计，不转储原文。包内一致性不证明来源签名/真实性或实际采集全覆盖。

## v3内容按需取原字节

```powershell
python scripts/read_content.py D:\recordings\session.zip D:\work\new-index.sqlite3 --event-id "<snapshot-id>" --field sourceHtml --output D:\work\new-page.html
python scripts/read_content.py D:\recordings\session.zip D:\work\new-index.sqlite3 --event-id "<screenshot-id>" --field image --output D:\work\new-image.png
python scripts/read_content.py D:\recordings\session.zip D:\work\new-index.sqlite3 --event-id "<response-id>" --field body --output D:\work\new-response.bin
```

field是payload顶层字面字段，不是JSON Pointer。请求正文一般bodyText，响应body，样式text，截图image；长表单forms.value.field映射同事件payload的formValueN。旧索引无archive_identity时需用新版indexer重新索引；无captured引用不是空字符串，不按URL补下载。

新工具核对整ZIP身份、manifest、**清单指定的时间线分块**、原事件/内容引用与实际size/hash；只复制原字节，不解码、执行或覆盖。默认1400MiB ZIP/展开、1280MiB单次输出，参数以字节计；实际事件/引用/正文和总额仍受该批1–20倍快照限制，不能用读取器大资源上限覆盖采集政策；索引器的旧兼容资源上限则是十进制MB，均不等同插件采集预算或内存上限。

当前[本地读取skill0.5.0](<../app/release/v0.5.0/extension-logic-clone-v0.5.0.zip>)只含代码/说明，不含记录/索引或密钥；DSH/Codex已备份同步。GitHub已发布v0.4.0的skill0.4.0.1保持原字节，未自动公开本次新版本。解压后以整个extension-logic-clone目录备份替换目标技能；不要覆盖其它skill。原v0.4.0发布字节保持不变；本轮配套v0.5.0插件程序更新，但不访问或删除真实录制。
