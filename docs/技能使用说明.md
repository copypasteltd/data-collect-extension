# 记录包解析技能 / Recording Analysis Skill

`$extension-logic-clone` 用于阅读本扩展导出的 ZIP，梳理用户实际走过的页面、操作、请求、状态和截图证据；用户要求构建时，可基于这些证据实现已观察到的页面和业务流程。技能在 Codex 中执行，插件侧边栏仍只有录制、停止、选择批次和导出。

## 安装 / Install

仓库版本位于 `app/skills/extension-logic-clone/`。将整个目录复制到 Codex 的技能目录，例如 Windows 上的 `%USERPROFILE%\.codex\skills\extension-logic-clone\`；若目标已存在，先检查其内容，再决定如何更新。安装后开启新的 Codex 会话以发现技能。

The repository copy lives at `app/skills/extension-logic-clone/`. Copy the whole directory into the user's Codex skills directory, such as `%USERPROFILE%\.codex\skills\extension-logic-clone\` on Windows or `~/.codex/skills/extension-logic-clone/` on macOS/Linux. Inspect an existing target before replacing it, then start a new Codex session.

## 调用 / Invoke

在 Codex 输入 `$extension-logic-clone`，同时说明 ZIP 路径、希望输出的位置，以及只需分析还是需要实现复现。例如：

```text
$extension-logic-clone 解析 D:\recordings\session.zip，整理页面、操作和接口证据，并在 D:\work\reconstruction 复现已观察到的流程。
```

In Codex, invoke `$extension-logic-clone` with the ZIP path, output location, and whether analysis or an implementation is requested.

## 索引 / Index

技能内置 `scripts/index_archive.py`，仅依赖 Python 3.9+ 标准库。它支持 v1/v2 记录包，验证 ZIP 路径、条目大小、清单、SHA-256 和事件数据，再把完整事件写入新建的 SQLite 文件。输出文件不会覆盖已有文件；源 ZIP 不会修改。标准输出只包含格式版本、校验结果和事件类型计数。

```powershell
python .\app\skills\extension-logic-clone\scripts\index_archive.py D:\recordings\session.zip --output D:\work\recording-index.sqlite3
```

输出目录必须已经存在。默认限制为 ZIP 2,048 MB、单文件展开 512 MB、总展开 8,192 MB、30,000 个文件和 100 万事件；单条事件最多 40,000,000 字节。前 3 项可通过 `--max-archive-mb`、`--max-entry-mb`、`--max-expanded-mb` 调整。索引仅引用 ZIP 中的资源路径，不会自动解压或执行资源。

The indexer validates archive paths, sizes, manifest, checksums, and events before creating a new SQLite index. It never overwrites an existing index or modifies the ZIP. Run `python .../index_archive.py --help` for configurable size limits. It does not extract or execute recorded resources.

## 分段重组 / Fragment Reconstruction

技能中的 `scripts/reconstruct_payload.py` 可以从已校验的 SQLite 索引重组事件引用的分段。指定事件 ID、引用字段的 JSON Pointer 和尚不存在的输出文件；工具会检查分段序号、数量、长度和结束确认。文件或画布的 Base64 内容可加 `--base64`，并用 `--expected-bytes` 核对字节数。

```powershell
python .\app\skills\extension-logic-clone\scripts\reconstruct_payload.py D:\work\recording-index.sqlite3 --event-id "<event-id>" --reference /payload/sourceReference --output D:\work\page.html
```

The skill includes `reconstruct_payload.py`. It reconstructs a referenced payload from a verified index and checks fragment sequence, length, and completion. Use `--base64` for byte payloads and `--expected-bytes` to verify their decoded size. Existing output files are not overwritten.

压缩计算样式可从同一索引解码；命令校验数据长度、gzip 完整性和条目数，输出文件不得已存在：

```powershell
python .\app\skills\extension-logic-clone\scripts\decode_computed_style.py D:\work\recording-index.sqlite3 --event-id "<style-event-id>" --output D:\work\styles.json
```

Use `decode_computed_style.py` to decode a compressed computed-style event from the verified index. It checks gzip integrity, decoded size, and entry count without overwriting existing output.

## 阅读和复现 / Interpretation

完整字段、事件关联和 SQLite 查询示例见技能内的 [archive-format.md](../app/skills/extension-logic-clone/references/archive-format.md)。按 `time, seq` 排列事件，按 `requestId` 关联网络记录，并结合标签页、框架、页面实例和截图时间核对页面证据；时间相近不等于因果确定。每一结论应关联事件 ID 和记录包内路径，缺失、未观察到或无法确认的内容必须标记为未知。

录制的原始 DOM 是采集时页面的序列化结果，不等同于原始 HTTP 字节或完整站点源码。浏览器权限、页面生命周期、截图频率和大小限制可能造成缺口；不能保证恢复未访问的分支、服务器内部逻辑或完整网站。复现时应将观察事实、推断和实现时补充的行为区分开，并使用隔离页面和本地模拟数据。

The format reference covers event links and SQLite queries. Treat proximity as a candidate relationship, not proof of causation. Distinguish observations, inferences, and missing evidence. Recorded DOM is not original server source; unvisited paths and server logic cannot be recovered reliably.

## 数据安全 / Data Handling

ZIP 和 SQLite 索引都可能包含原始密码、Cookie、令牌和业务数据，且默认不加密。技能不修改或自动脱敏原包；不要将原包、索引或真实数据提交到 GitHub，也不要未经用户明确授权上传到其他服务或对真实网站重放。

Archives and SQLite indexes can contain unmasked credentials and business data and are not encrypted by default. The skill does not alter or automatically redact the source. Do not commit or upload real recordings or indexes, or replay them against a real site without explicit authorization.
