# 逻辑记录 v0.1.0 开发验证版 / Logic Recorder v0.1.0 Preview

通过 Chrome 侧边栏录制已授权的业务操作，停止后选择录制批次并导出 ZIP。侧边栏不展示采集内容，也不提供插件内查看、导入或复现界面。独立的 `$extension-logic-clone` 技能可分析导出的记录并协助重建已观察流程。

Record authorized workflows through the Chrome side panel, stop recording, and export a selected batch as a ZIP. The side panel does not display captured content or provide in-extension viewing, import, or replay. The separate `$extension-logic-clone` skill analyzes exports and helps reconstruct observed workflows.

## 下载与安装 / Downloads and installation

- `logic-recorder-chrome-v0.1.0.zip`: 解压后，在 Chrome 125 或更高版本的 `chrome://extensions` 中打开开发者模式，选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。 / Extract the ZIP, enable Developer mode at `chrome://extensions` in Chrome 125 or later, choose “Load unpacked,” and select the extracted folder containing `manifest.json`.
- `extension-logic-clone-v0.1.0.zip`: 将解压后的 `extension-logic-clone` 文件夹放入当前用户的 `.codex/skills/`，然后开启新的 Codex 会话。索引工具需要 Python 3.9 或更高版本。 / Place the extracted `extension-logic-clone` folder in the current user's `.codex/skills/` directory and start a new Codex session. The indexer requires Python 3.9 or later.
- `SHA256SUMS.txt`: 两个下载文件的 SHA-256 校验值。 / SHA-256 checksums for both downloads.

## 数据与限制 / Data and limitations

录制包保留浏览器可提供的原值，可能包含密码、Cookie 和其他凭据；ZIP 不加密。浏览器权限、时序和采集上限可能造成缺失，记录不能保证恢复未访问分支、原站源码或服务端逻辑。

Recordings retain browser-provided values and may contain passwords, cookies, and credentials; ZIPs are not encrypted. Permissions, timing, and capture limits can cause gaps. Recordings do not guarantee recovery of unvisited paths, original source code, or server logic.
