# 逻辑记录 v0.1.5 开发验证版 / Logic Recorder v0.1.5 Preview

修复后台重启后录制状态读取失败时，侧边栏显示录制中却无法停止的问题。停止操作会尝试关闭采集并安全标记中断批次，保留已保存的数据和已完成批次；本地存储写入或清理失败时明确报告，存储恢复后可重新读取批次。

停止请求核对当前批次并拒绝重复操作。停止回复超时但后台随后完成时，侧边栏状态刷新会清除过期提示。

Fix a case where a failed recording-state read after a worker restart left recording visible but could block Stop. Stop attempts to close collectors and safely mark an unfinished batch interrupted, retaining saved data and preserving completed batches. Local write and cleanup failures are reported; batches can be read again after storage recovers.

Stop checks the active session and rejects duplicate requests. If its reply times out but the worker finishes later, the side panel clears the stale timeout after status updates.

已在隔离浏览器中注入恢复读取失败、写入失败及恢复，验证停止、中断数据导出、重复和过期停止请求及迟到回复；同时回归正常恢复、慢标签页和正式版 Chrome 录制。尚未在 macOS 真机验证，客户截图不能单独确定故障原因。

Tested recovery read and write failures, storage recovery, stopping, interrupted-data export, stale and duplicate stops, delayed replies, normal recovery, slow tabs, and recording in official Chrome. macOS hardware has not yet been tested; the customer's screenshot alone does not establish its cause.

## 安装 / Installation

- `logic-recorder-chrome-v0.1.5.zip`：解压后，在 Chrome 125 或更高版本的 `chrome://extensions` 中启用开发者模式并加载包含 `manifest.json` 的目录。 / Extract and load the directory containing `manifest.json` via Developer mode at `chrome://extensions` in Chrome 125 or later.
- `extension-logic-clone-v0.1.5.zip`：将 `extension-logic-clone` 文件夹解压到当前用户的 `.codex/skills/` 并开启新的 Codex 会话；索引工具需要 Python 3.9+。 / Extract `extension-logic-clone` into the current user's `.codex/skills/` and start a new Codex session. The indexer requires Python 3.9+.
- `SHA256SUMS.txt`：附件校验值。 / SHA-256 checksums for the archives.

记录包可能包含密码、Cookie 和其他凭据，ZIP 不加密；浏览器限制仍可能导致记录缺失。 / Recordings may contain passwords, cookies, and other credentials; ZIPs are not encrypted. Browser limits can still cause gaps.
