# 逻辑记录 v0.1.2 开发验证版 / Logic Recorder v0.1.2 Preview

修复普通 HTTP 网页中 `crypto.randomUUID is not a function` 导致页面事件无法发送、反复报错的问题。受影响的旧录制中未保存的事件无法恢复，请更新后重新录制。

Fix repeated `crypto.randomUUID is not a function` errors that prevented page events from being sent on ordinary HTTP sites. Events missing from earlier affected recordings cannot be recovered; record those workflows again after updating.

在正式版 Chrome 中使用非安全 HTTP 测试地址验证了录制、导出、输入及请求事件，并检查扩展错误列表；自动化测试也检查 UUID 格式和重试时的标识一致性。尚未完成 macOS 真机验证。

Verified recording, export, input and request events, and the extension error list in official Chrome using an insecure HTTP test address. Automated tests also check UUID format and retry identity. macOS hardware has not yet been tested.

## 安装 / Installation

- `logic-recorder-chrome-v0.1.2.zip`：解压后，在 Chrome 125 或更高版本的 `chrome://extensions` 中启用开发者模式并加载包含 `manifest.json` 的目录。 / Extract and load the directory containing `manifest.json` via Developer mode at `chrome://extensions` in Chrome 125 or later.
- `extension-logic-clone-v0.1.2.zip`：将其中的 `extension-logic-clone` 文件夹解压到当前用户的 `.codex/skills/`，然后开启新的 Codex 会话；索引工具需要 Python 3.9+。 / Extract the `extension-logic-clone` folder into the current user's `.codex/skills/` directory and start a new Codex session. The indexer requires Python 3.9+.
- `SHA256SUMS.txt`：附件校验值。 / SHA-256 checksums for the archives.

记录包可能包含密码、Cookie 和其他凭据，ZIP 不加密；浏览器限制仍可能导致记录缺失。 / Recordings may contain passwords, cookies, and other credentials; ZIPs are not encrypted. Browser limits can still cause gaps.
