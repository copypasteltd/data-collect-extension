# 逻辑记录 v0.2.0 开发预览版 / Logic Recorder v0.2.0 Preview

本预览版增强已访问页面的原始 DOM、样式、截图、画布、操作、网络请求和浏览器数据记录，增加大数据分段、完整性与缺口标记、可追溯索引及 `$extension-logic-clone` 解析工具。扩展在 Chrome 侧边栏提供开始、停止、批次选择和导出。

This preview expands capture of visited pages, original DOM, styles, screenshots, canvas, interactions, network requests, and browser data. It adds fragmentation, integrity and gap reporting, traceable indexes, and the `$extension-logic-clone` analysis skill. The Chrome side panel provides recording, stopping, batch selection, and export.

**验收状态：** 20261111 内容更新细则的 01–26 尚未全部完成验收。部分嵌入框架关联、动态页面及异常场景仍有缺口；浏览器拒绝或没有提供的数据无法保证采集。WebGL 不保留绘图缓冲时，画布 PNG 可能与屏幕不同，应结合截图并检查记录中的未验证标识。大包导出可能需要较长时间。

**Acceptance status:** Items 01–26 in the 2026-11-11 specification have not all passed acceptance. Some embedded-frame associations, dynamic-page behavior, and failure cases remain incomplete. Data unavailable or denied by the browser cannot be guaranteed. WebGL canvas PNGs can differ from the screen when the drawing buffer is not preserved; consult screenshots and the recorded unverified status. Large exports can take substantial time.

验证包括 122 项自动测试、8 项技能测试和前一构建的 46 项 Windows 正式版 Chrome 采集矩阵；XML 和 WebGL 新增样本分别通过独立浏览器测试。0.2.0 构建单独通过侧边栏两次录制、停止、批次选择、导出与技能索引检查。最新完整矩阵按用户要求提前停止，不能计为通过。按用户要求未进行 macOS 真机测试。

Validation includes 122 automated tests, 8 skill tests, and a 46-scenario official Windows Chrome matrix on the preceding build; the new XML and WebGL scenarios passed individually. The 0.2.0 build separately passed two side-panel recordings, stopping, batch selection, export, and skill indexing. The latest full matrix was stopped early at the user's request and is not reported as passing. macOS hardware was not tested at the user's request.

## 安装 / Installation

- `logic-recorder-chrome-v0.2.0.zip`：解压后，在 Chrome 125 或更高版本的 `chrome://extensions` 中启用开发者模式，选择“加载已解压的扩展程序”，并选择包含 `manifest.json` 的文件夹。插件运行只需 Chrome。 / Extract, enable Developer mode at `chrome://extensions` in Chrome 125 or later, and load the folder containing `manifest.json`. Only Chrome is required to run the extension.
- `extension-logic-clone-v0.2.0.zip`：解压到当前用户的 `.codex/skills/`，保留 `extension-logic-clone` 文件夹，并开启新的 Codex 会话；索引脚本需要 Python 3.9+。 / Extract the `extension-logic-clone` folder into the current user's `.codex/skills/` and start a new Codex session; the indexer requires Python 3.9+.
- `SHA256SUMS.txt`：附件校验值。 / SHA-256 checksums for the archives.

记录保留浏览器提供的原值，ZIP 不加密，可能包含密码、Cookie 和其他凭据。完整功能、限制及使用方法见 [中文 README](https://github.com/copypasteltd/data-collect-extension/blob/v0.2.0/README.md)、[English README](https://github.com/copypasteltd/data-collect-extension/blob/v0.2.0/README.en.md) 和 [实施进度](https://github.com/copypasteltd/data-collect-extension/blob/v0.2.0/docs/20261111内容更新实施进度.md)。

Recordings retain browser-provided values and are not encrypted; they may contain passwords, cookies, and other credentials. See the linked READMEs and implementation progress for details and limitations.
