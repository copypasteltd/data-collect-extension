# v0.4.0 — 轻量业务记录版

已按用户明确授权正式发布：[GitHub Release v0.4.0](<https://github.com/copypasteltd/data-collect-extension/releases/tag/v0.4.0>)，扩展0.4.0配读取skill0.4.0.1；标签指向3b5626a5ba88370d521756737a9d35b5340d52a2。旧v0.3.0不变。此前本地交付/安装记录保留历史，公开正式包使用最新skill及可分发说明。

## 变化

根业务标签+必要授权框架+一个可信归因子页；保关键动作/表单前后/DOM状态/必要CSS资源/视口PNG/API样本。撤掉全profile、全计算样式/主题字典、Cookie/Storage/IDB/Cache镜像、全页/Canvas像素、上传/全JS/实时正文等默认重型义务。

64MiB总预算、48MiB提醒、普通63MiB+1MiB收尾、类别子预算及2MiB正文在接纳前执行。内容SHA256去重，事件/新内容/容量同事务；v3导出只打包落盘数据和轻清单，不展开主题/字段分析。旧数据库不打开、不迁移、不删除，新列表只显示新轻量批次。

## 实证

445JS（72新flow）与12+16Python通过；Chrome真实预算/owner/幂等/seal、60秒样本8门通过；20轮短业务160门全部通过，P95停止2436ms/导出2703ms，ZIP最大329596B；独立60秒样本ZIP562491B，停止1837ms/导出2366ms。独立只包重建13项真实UI通过，但不声称原站源码/像素精确或所有站点规模均可保证。
