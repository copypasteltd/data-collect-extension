# 逻辑记录 v0.1.1 开发验证版 / Logic Recorder v0.1.1 Preview

## 修复 / Fixes

- 修复录制准备时打开的标签页可能遗漏；更早注册采集器并跟踪这些标签页的后续操作和请求。 / Track tabs opened while recording starts, register the collector earlier, and capture their subsequent actions and requests.
- 修复停止后迟到的调试连接可能残留并影响下一批录制；同一标签页的连接尝试按顺序完成。 / Close late debugger connections after stopping and serialize connection attempts for the same tab across recordings.
- 端到端测试检查导出包中实际存在 JPEG 截图，并在普通和两倍像素密度下运行。尚未进行 macOS 真机测试。 / End-to-end tests check exported JPEG screenshots at normal and double simulated pixel density. macOS hardware has not yet been tested.

## 安装 / Installation

- `logic-recorder-chrome-v0.1.1.zip`：解压后，在 Chrome 125 或更高版本打开 `chrome://extensions`，启用开发者模式并加载包含 `manifest.json` 的解压目录。 / Extract and load the directory containing `manifest.json` via Developer mode at `chrome://extensions` in Chrome 125 or later.
- `extension-logic-clone-v0.1.1.zip`：将其中的 `extension-logic-clone` 文件夹解压到当前用户的 `.codex/skills/`，然后开启新的 Codex 会话；索引工具需要 Python 3.9+。 / Extract the `extension-logic-clone` folder into the current user's `.codex/skills/` directory and start a new Codex session. The indexer requires Python 3.9+.
- `SHA256SUMS.txt`：附件校验值。 / SHA-256 checksums for the archives.

记录包可能含密码、Cookie 和其他凭据，ZIP 不加密；浏览器限制仍可能导致记录缺失。 / Recordings may contain passwords, cookies, and other credentials; ZIPs are not encrypted. Browser limits can still cause gaps.

使用方式和完整限制见[中文说明](https://github.com/copypasteltd/data-collect-extension/blob/v0.1.1/README.md)和 [English README](https://github.com/copypasteltd/data-collect-extension/blob/v0.1.1/README.en.md)。
