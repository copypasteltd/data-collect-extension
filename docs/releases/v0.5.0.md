# v0.5.0 本地交付：限额可设置，默认20倍

侧栏新增容量、待处理队列、页面采样三组1–20整数倍率，默认及最大20；可保存/恢复默认，重开保留，录制中改设置只下一批生效。

单批1280MiB=1.25GiB（约1.2GB），提醒960MiB，普通1260MiB/收尾20MiB，单正文40MiB。正文/DOM/资源/截图/元数据480/320/160/240/80MiB；队列/采样同步放宽，时间/权限/根流程范围保持不变。旧批固定原限额，未重写数据。

长内容确认分片、分页及OPFS流式STORE导出；SHA/CRC按块校验，下载后只清本次临时输出。配套skill0.5.0可读取每批设置、核账本/封存/实际事件与引用限制。

500项JS和58项Python通过，原生1/20两批及Unicode前后值/3MiB正文和DOM、130条小片/Stop独立、320px页面通过；实际72MiB存储和75511309B磁盘ZIP导出通过。**1.25GiB整批满载未实测**，不外推任意网站/内存/磁盘保证；STORE包可能比旧deflate包大。

本机原目录已备份并更新文件，未代刷新/开启Chrome，不清旧数据库。DSH/Codex skill已同步并实际核原字节。源码按项目约定同步origin。当前这是本地release，未自动公开GitHub v0.5.0；已发布v0.4.0不变。
