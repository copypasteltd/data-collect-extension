# 逻辑记录 v0.1.4 开发验证版 / Logic Recorder v0.1.4 Preview

修复多个慢标签页顺序准备时，侧边栏可能出现“后台响应超时”的问题。创建批次后立即确认启动，后台每个准备阶段最多并发处理四个标签页；准备期间仍可停止，并导出已保存的部分记录。

录制状态与批次列表读取分离：批次列表暂时无响应时仍可刷新录制状态和停止；读取恢复后对应提示自动消失。启动确认后若准备失败，批次标记为中断并保留已保存数据。

Fix a case where sequential preparation of slow tabs could cause a background response timeout. Startup is acknowledged once the batch is created, with up to four tabs prepared concurrently per phase. Stop remains available during preparation, and saved partial data can be exported.

Live status is independent of batch-list reads, so a stalled list does not block status updates or Stop. Its error clears after recovery. A preparation failure after acknowledgment marks the batch interrupted and preserves saved data.

已测试慢标签页、批次列表读取无响应及恢复、准备期间停止和导出，并回归后台恢复及正式版 Chrome 的 HTTP 录制。尚未在 macOS 真机验证，客户截图本身不能确定其后台超时的具体原因。

Tested slow tabs, a stalled and recovered batch list, stopping and exporting during preparation, background recovery, and HTTP recording in official Chrome. macOS hardware has not yet been tested; the customer's screenshot alone does not establish the underlying cause of its timeout.

## 安装 / Installation

- `logic-recorder-chrome-v0.1.4.zip`：解压后，在 Chrome 125 或更高版本的 `chrome://extensions` 中启用开发者模式并加载包含 `manifest.json` 的目录。 / Extract and load the directory containing `manifest.json` via Developer mode at `chrome://extensions` in Chrome 125 or later.
- `extension-logic-clone-v0.1.4.zip`：将其中的 `extension-logic-clone` 文件夹解压到当前用户的 `.codex/skills/`，然后开启新的 Codex 会话；索引工具需要 Python 3.9+。 / Extract `extension-logic-clone` into the current user's `.codex/skills/` directory and start a new Codex session. The indexer requires Python 3.9+.
- `SHA256SUMS.txt`：附件校验值。 / SHA-256 checksums for the archives.

记录包可能包含密码、Cookie 和其他凭据，ZIP 不加密；浏览器限制仍可能导致记录缺失。 / Recordings may contain passwords, cookies, and other credentials; ZIPs are not encrypted. Browser limits can still cause gaps.
