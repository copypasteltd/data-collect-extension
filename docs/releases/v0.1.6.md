# 逻辑记录 v0.1.6 开发验证版 / Logic Recorder v0.1.6 Preview

修复后台重启后会话状态无法读取时，停止请求可能无法进入收尾的问题。扩展会核对已保存的批次并尝试中断；多个未结束批次或归属不明确时会提示等待状态恢复，避免误停其他批次。

异常清理按页面框架核对采集器关闭回复；旧采集器未关闭时，后续批次会核对身份并接管，在确认就绪或记录缺口后进入录制状态。中断归档写入失败会保留重试项，存储恢复后可再次选择并导出已保存的数据；归档与清理同时失败时分别报告。

Fix a case where a session-state read failure after worker restart could block Stop. Saved batch information is checked before attempting interruption; ambiguous ownership or other unfinished batches cause a retry message instead of stopping another session.

Exceptional cleanup verifies collector replies per frame. New sessions can replace stale collectors and enter recording after readiness checks or a recorded gap. Failed interruption writes are retried so saved data can be exported after storage recovery; simultaneous archival and cleanup failures are both reported.

已在隔离浏览器和 Windows 正式版 Chrome 中测试会话读取超时、旧停止请求、系统时间变化、框架清理失败、延迟接管、写入失败恢复和导出，并回归多标签启动及停止生命周期。尚未在 macOS 真机验证，客户截图不能单独确定故障原因。

Tested session read timeouts, stale stops, clock changes, failed frame cleanup, delayed collector takeover, failed-write recovery and export, multi-tab startup, and stop lifecycle in isolated browsers and official Chrome on Windows. macOS hardware has not yet been tested; the customer's screenshot alone does not establish its cause.

## 安装 / Installation

- `logic-recorder-chrome-v0.1.6.zip`：解压后，在 Chrome 125 或更高版本的 `chrome://extensions` 中启用开发者模式并加载包含 `manifest.json` 的目录。 / Extract and load the directory containing `manifest.json` via Developer mode at `chrome://extensions` in Chrome 125 or later.
- `extension-logic-clone-v0.1.6.zip`：将 `extension-logic-clone` 文件夹解压到当前用户的 `.codex/skills/` 并开启新的 Codex 会话；索引工具需要 Python 3.9+。 / Extract `extension-logic-clone` into the current user's `.codex/skills/` and start a new Codex session. The indexer requires Python 3.9+.
- `SHA256SUMS.txt`：附件校验值。 / SHA-256 checksums for the archives.

记录包可能包含密码、Cookie 和其他凭据，ZIP 不加密；浏览器限制仍可能导致记录缺失。 / Recordings may contain passwords, cookies, and other credentials; ZIPs are not encrypted. Browser limits can still cause gaps.
