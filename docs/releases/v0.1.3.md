# 逻辑记录 v0.1.3 开发验证版 / Logic Recorder v0.1.3 Preview

修复准备和停止过程中侧边栏无法停止录制或长时间等待的问题。准备期间可点击停止，已保存数据作为中断批次保留并可导出；多个页面并行收尾，超时或存储异常会标记中断。迟到的采集器注册和停止消息按批次隔离，避免影响后续录制。

快速切换标签后开始录制时，以实际活动标签为准，避免侧边栏缓存过期造成误报。

Fix cases where the side panel could not stop a recording during preparation or had to wait excessively during finalization. Stopping during preparation retains saved data as an interrupted, exportable batch. Pages finalize concurrently, timeouts and storage failures mark a batch as interrupted, and late collector operations are isolated by session.

Starting after a quick tab switch uses the actual active tab instead of a stale sidebar cache.

已验证准备阶段停止、部分导出、多页面收尾、超时、迟到消息、立即重录、侧边栏重开，以及正式版 Chrome 的 HTTP 录制。尚未在 macOS 真机验证。

Tested stopping during preparation, partial export, concurrent page finalization, timeouts, late messages, immediate restart, reopening the side panel, and HTTP recording in official Chrome. macOS hardware has not yet been tested.

## 安装 / Installation

- `logic-recorder-chrome-v0.1.3.zip`：解压后，在 Chrome 125 或更高版本的 `chrome://extensions` 中启用开发者模式并加载包含 `manifest.json` 的目录。 / Extract and load the directory containing `manifest.json` via Developer mode at `chrome://extensions` in Chrome 125 or later.
- `extension-logic-clone-v0.1.3.zip`：将其中的 `extension-logic-clone` 文件夹解压到当前用户的 `.codex/skills/`，然后开启新的 Codex 会话；索引工具需要 Python 3.9+。 / Extract the `extension-logic-clone` folder into the current user's `.codex/skills/` directory and start a new Codex session. The indexer requires Python 3.9+.
- `SHA256SUMS.txt`：附件校验值。 / SHA-256 checksums for the archives.

记录包可能包含密码、Cookie 和其他凭据，ZIP 不加密；浏览器限制仍可能导致记录缺失。 / Recordings may contain passwords, cookies, and other credentials; ZIPs are not encrypted. Browser limits can still cause gaps.
