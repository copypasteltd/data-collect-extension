# v0.3.0 — 原生Windows本地release

本版收口为四操作的浏览器证据记录工具：开始、停止、选择批次、导出。用户明确不建设隔离环境，本次直接在当前Windows原生环境编译和验证。

## 修复

- 独立批次Outcome及提交未知/失败区分，producer sticky核验状态不被迟到ACK清空。
- 分段End/Failure/late-part、UTF16/safe integer跨JS/Python一致。
- 会话owner任务/写链、停止准入关闭、同事务seal和不可变水位；补停止封存读取deadline。
- 字典来源分组、可选producer/exporter来源和固定大小存储诊断。
- 停止/导出状态分离、下载确认poll+有界等待、超时尽力取消及可重试。
- 验证runner、清理回执、测试profile删除保护与构建输入身份；故障测试适配append-only writer但保留关键断言。
